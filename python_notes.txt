---------------------

name = "Rahul"

These are two different variables.

        total += number

    return total

**KWARGS
--------

    print(data)

person(name="Rahul", age=20)

27. INHERITANCE
==================================================

Inheritance allows one class to inherit another class.

class Animal:

    def speak(self):
        print("Animal speaks")


class Dog(Animal):

    def bark(self):
        print("Dog barks")


dog = Dog()

dog.speak()
dog.bark()


==================================================
28. POLYMORPHISM
==================================================

Different classes can use the same method name.

class Dog:

    def speak(self):
        print("Woof")


class Cat:

    def speak(self):
        print("Meow")


animals = [Dog(), Cat()]

for animal in animals:
    animal.speak()


==================================================
29. ENCAPSULATION
==================================================

Encapsulation means controlling access to internal data.

Python commonly uses naming conventions such as:

class Person:

    def __init__(self):
        self._name = "Rahul"


Double underscore can trigger name mangling:

class Person:

    def __init__(self):
        self.__secret = "value"

32. MAP / FILTER / REDUCE
==================================================

MAP
---

numbers = [1, 2, 3, 4]

result = map(lambda x: x * 2, numbers)

print(list(result))


FILTER
------

numbers = [1, 2, 3, 4, 5]

result = filter(lambda x: x % 2 == 0, numbers)

print(list(result))


REDUCE
------

from functools import reduce

numbers = [1, 2, 3, 4]

result = reduce(lambda a, b: a + b, numbers)

print(result)

34. GENERATORS
==================================================

Generators produce values lazily.

def numbers():
    yield 1
    yield 2
    yield 3

for number in numbers():
    print(number)


Why generators?

They can save memory when working with large amounts of data.


==================================================
35. DECORATORS
==================================================

A decorator modifies or extends the behavior of a function.

def decorator(func):

    def wrapper():
        print("Before")
        func()
        print("After")

    return wrapper


@decorator
def hello():
    print("Hello")


hello()

==================================================
43. SQLITE
==================================================

Example:

import sqlite3

connection = sqlite3.connect("database.db")

cursor = connection.cursor()

cursor.execute("""
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY,
    name TEXT,
    age INTEGER
)
""")

connection.commit()

connection.close()


INSERT DATA
-----------

connection = sqlite3.connect("database.db")

cursor = connection.cursor()

cursor.execute(
    "INSERT INTO users (name, age) VALUES (?, ?)",
    ("Rahul", 20)
)

connection.commit()
connection.close()


READ DATA
---------

connection = sqlite3.connect("database.db")

cursor = connection.cursor()

cursor.execute("SELECT * FROM users")

rows = cursor.fetchall()

for row in rows:
    print(row)

connection.close()


IMPORTANT:

Use parameterized SQL queries instead of building SQL by
concatenating untrusted user input.
